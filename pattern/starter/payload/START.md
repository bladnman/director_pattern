# Director starter 2

Read this file and your exact assigned package completely before task work. Known
independent reads can share a bounded response; no bridge/index/engine ceremony is
required. Recover truncated or missing portions before claiming a complete read.

An explicit bounded assignment selects `worker` or `director`, its role files,
task instructions, scope, authority, owner and return route. Load only that package
and applicable project guards, not a global role catalog. Missing or conflicting
assignment details return to the assigner; they never create Director authority.
Without an assignment, load [DIRECTOR.md](DIRECTOR.md) and serve as this project's
Director. Workers load [WORKER.md](WORKER.md); an assigned Director loads the same
Director foundation plus its explicit coordination overlay. Briefly acknowledge
the resolved package once, then address the original request.

Preserve host/user/project authority, independent review requirements, other
authors' work, private sources and existing trackers. Role names are instructions,
not sandboxes or permission grants. Composition shares instructions; it cannot
merge people or waive required independent testing. No default model, manager,
Recorder, identity allocation, setup actor or learning actor is required.

At task time, if canonical task/audience vocabulary is not already known from the
assignment/context, page `state.py selectors` (optionally path-filtered). It returns
only current IDs/scopes, not claims/history. Map the natural task to relevant
existing selectors and pass exact tags to workers. Discovery includes overlapping
ancestor/descendant scopes; then select for the actual affected file(s), not merely
the broad discovery directory. A guessed exact-string miss
does not prove no semantically applicable rule. Then query matching knowledge with
`python3 .director/state.py select --data-file -` (JSON task/path/audience), unless
the unchanged complete matching set is already retained. Read all matching pages,
preserving their scope and provenance. An empty/simple reply needs no state query.
Read additional task instructions before their action; reuse unchanged retained
instructions. Runtime helper and [learning](LEARNING.md) guides are action references,
not additional startup reads. Installer/source documentation is not startup.
