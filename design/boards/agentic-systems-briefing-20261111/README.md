## The telling (24 steps)

1. **An agentic system** — one person/one agent today; a system built around a
   domain; a request fans out; one answer comes back.
2. **The Director Pattern** — one way in and out; delegation with records; shared
   domain context; traceable and controllable.
3. **Learning and growing** — domain lessons; the Architect watches; grow a team
   member; shrink what is unused.
4. **Across systems** — a shared message layer: drop, gather by recipient,
   "Anything for me?", reply and resume.
5. **People in the loop** — people use the same layer; answers go back in;
   decision-makers can also sit inside a system and work with its Director
   directly; start where it helps.
6. **At scale** — zoom out to an organization of systems of different sizes,
   shapes and people/agent mixes on one message layer; it grows one domain at a
   time; a live activity card shows who is talking to whom, and pauses or redirects work from the same place; open one system only when it
   needs diagnosis.

The request is deliberately generic (no Fieldwork story). Team names and the
database example are illustrations, not a prescribed organization. The Architect
and the shared message layer are proposed mechanisms, not shipped behavior.
