# Making the system feel alive

Progressive diagnosis and art direction for the five connected Inside agentic systems explainers. This is explanatory research, outside the installable method.

Read [report.md](report.md) for the diagnosis, current observations and remaining proof. Open [slides.html](slides.html) for the five-page graphical telling. Its inline SVG diagrams illustrate a direction; they do not depict an accepted revised result.

The files have no network dependencies. To serve this folder without Tinka, run from the repository root:

```sh
python3 -m http.server 8878 --bind 127.0.0.1 --directory design/boards
```

Open `http://127.0.0.1:8878/research/2026-11-10-living-system-art/slides.html`. Previous/Next and the left/right arrow keys change pages. Stop that temporary server when finished. The containing `design/boards` root also resolves the report's local links to current and preserved presenter versions.

In Tinka, use board `research-2026-11-10-living-system-art`, linked from Research and diagnosis and Inside agentic systems. The markdown and slides share no host SDK or required messages.
